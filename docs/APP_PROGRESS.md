# BoarderLess App Progress

更新日期：2026-09-30

## 已完成並驗證

- 自製 Compose Shell / Content 視覺層，不依賴 Material 3。
- UI 圖標語言：新增不依賴平台圖示庫的共用線性向量圖標，依動作語意自動套用到桌面工具列、手機中央選單、Workspace／Library／History 等面板；圖標與文字標籤並存，Disabled／Accent／鍵盤焦點狀態沿用同一套色彩與無障礙按鈕語意，Android、Desktop、iOS、JS 與 Wasm 共用同一實作。剪下、複製、貼上、再製與組成群組另有一致的專用圖標，不再只以文字辨識。
- Accessibility：可持久化的 Reduce Transparency／Reduce Motion、高對比 Shell fallback、Node／Group 語意狀態、Shell 按鈕可見焦點環與 44dp 最小觸控高度；Node／Group 可由 Tab／Shift+Tab 聚焦並同步 selection，支援鍵盤建立、Fit、方向鍵微移和 Enter 編輯選取思想。聚焦單一思想後，Command Palette 會提供可依目標文字搜尋的「連接到…」命令；選取兩個思想時也可搜尋並以鍵盤建立「相關／支持／衝突」relation。既有 relation 也可依來源、目標、意圖或標籤搜尋，執行後會置中兩端並直接選取連線供 Inspector 檢查。所有入口沿用拖曳 connector 的 history 與同步流程。Resize／Rotate 控制點除了拖曳外，也提供 VoiceOver 可直接啟用的放大一步與順時針旋轉 15 度動作。Command Palette 的全畫面 scrim 與結果內容採獨立語意節點，不會再讓 iOS VoiceOver 把所有命令合併成一顆巨大按鈕；每筆結果可分別聚焦與執行。
- Infinite Canvas：滑鼠／單指平移、滾輪／雙指定點縮放、工具列與 Command Palette 的縮小／放大／100%／Fit 控制、涵蓋 Node／Group 與旋轉邊界的 Fit Content、viewport 保存；座標、尺寸、旋轉與 zoom 在 domain 邊界拒絕 NaN／Infinity，避免損壞偏好或異常 projection 進入渲染與 hit testing。桌面寬畫面提供包含內容與目前視窗範圍的 Minimap，滑鼠點擊任意位置可在保留 zoom 下重新置中，鍵盤／螢幕閱讀器啟用則置中至正式內容的幾何中心；窄畫面自動隱藏避免遮住 Inspector。
- Text Node：暫態空白草稿、完成輸入後單次建立與儲存、空白取消不留下 history、即時編輯、選取、Shift 多選，以及可切換的 Area select 框選模式；框選依旋轉後形狀命中，Shift-drag 可累加 selection。支援自由移動與刪除。觸控裝置的軟鍵盤提供 `Done` action 並沿用單次 commit／history／save 流程，桌面實體鍵盤仍可用 Tab／Escape 完成編輯。
- Diagram shapes：Text Node 支援圓角矩形、流程矩形、橢圓、判斷菱形、開始／結束膠囊、輸入／輸出平行四邊形、系統六邊形、波浪底文件與含頂部橢圓細節的資料庫圓柱；Inspector 可單選或多選切換，並完整進入 Undo／Redo、Workspace `shapeToken` 儲存、剪貼簿 v3 與 Quick Scheme。形狀渲染、指標命中、connector drop 與關係線端點皆使用實際輪廓，不會把透明角落視為節點。關係線依節點相對位置使用水平／垂直 port 與直角折線，並把其他 Node 的旋轉外框加安全距離視為障礙，從候選路徑中選擇最短且不穿過障礙的路線；選取命中、箭頭方向與標籤中點皆沿同一條完整 polyline 計算。多選同一上層的未鎖定 Node 後，可由 Inspector 或 Command Palette 執行由左至右流程、依 Relation 方向建立樹狀階層、把連線數最多的核心置中並將其餘節點環狀排列，或依不同節點尺寸自動建立不重疊的緊湊網格；三個以上 Node 另可保留可視首尾邊界，依各自旋轉後寬高執行水平／垂直等距分布。兩個以上 Node 可依旋轉後可視邊界執行左／水平置中／右與上／垂直置中／下六種對齊。尺寸與形狀保持不變，整批位置更新為單一可 Undo 的 `TransformObjectsOperation`，循環／孤立節點則以穩定 z-order 補排。Object Library 可搜尋標題與說明，並直接拖曳流程、開始／結束、判斷、輸入／輸出、橢圓、系統、文件與資料庫節點；Command Palette 也提供所有非預設圖形的中英文搜尋與鍵盤建立入口，沿用空白草稿取消不寫入、完成文字後才建立單一 history operation 的流程。另提供流程圖、泳道圖、組織圖、架構圖、關係圖、拓樸圖與樹狀圖起始範本，七種範本除了物件庫外，也可直接由 Command Palette 以中英文名稱搜尋並一鍵插入中央；泳道以可繼續編輯的 Group 容器保存責任區域，所有範本以單一 transaction 進入 Undo／Redo。既有資料未含 `shapeToken` 時向後相容為原本的圓角卡片。
- History：operation transaction、Undo / Redo、版本衝突檢查，以及允許儲存中繼續編輯的 FIFO optimistic submission queue；App 與後端統一採用「每個 atomic transaction 推進一次 Workspace version」，子操作仍依序推進各物件版本，且 domain 拒絕非正數的 Object／Relation version 與負數 Workspace version，避免群組／貼上／AI proposal 產生 optimistic 版本漂移。刪除 operation 另會原子驗證完整 Group subtree 與精確 relation cascade 快照，避免 App 留下 dangling parent／relation，或和後端自動 relation cascade 分歧；重複 relation 刪除快照也會在建立 history 前拒絕。失敗或衝突時整批未確認操作會回到伺服器權威狀態。History 面板會顯示伺服器 Workspace version、pending save 數量、最多 30 筆可 Undo／Redo 的本機操作摘要，以及從正式 operation log 讀取的最近 100 筆跨重開伺服器活動（actor、版本、server sequence、類型與時間）。面板明確提示本機 history 在重開或遠端 catch-up 後重設；目前不提供跨版本任意跳轉，避免越過後端尚未支援的 soft-delete restore。協調器測試覆蓋相依操作 base version 推進、conflict、回應遺失後 reconcile 與完全離線。
- Node／Group 控制：顏色、鎖定、layer 逐層前移／後移與置頂／置底、依群組階層與 z-order 顯示的 Layers 導覽面板、Inspector 調整，以及可直接拖曳的 resize／rotate handles；單選未鎖定 Node 時，Inspector 另提供以裝置無關邏輯單位輸入 X、Y、寬、高與旋轉角度的精準變形，一次套用只建立一筆可 Undo 的 transform operation，過小尺寸會依既有控制點規則收斂至最低值，非數值、無限值與危險的大範圍輸入則拒絕。Layers 可選取、置中並操作未鎖定物件，異常 parent／cycle 也不會讓物件遺失或重複。多選 Inspector 會明確顯示 Lock／Color 的 Mixed state。多選拖曳不會移動鎖定節點；Layer 重排保留多選物件的相對順序；多選縮放／旋轉以共同中心變形整體版面，兩者皆可用單一 history operation 撤銷。
- Canvas 控制：網格顯示、網格吸附（拖曳時可按 Option/Alt 暫時略過）、物件邊緣／中心吸附與輔助線、裝置本機的 Workspace 背景偏好。多選與群組以拖曳錨點計算單一網格吸附 delta，所有物件保持原本相對位置。背景要成為共享且可 Undo 的正式 Workspace 樣式仍需 `BAI-005` operation 合約。
- Relation：方向、意圖、箭頭、跟隨端點移動、保存與重開；單選 Node 顯示可拖曳 connector handle，可預覽並放到另一個含旋轉命中的 Node 上建立 `relates →`；鍵盤或 VoiceOver 啟用同一控制點時則開啟已篩選的「連接到…」目標選擇器。亦支援點線命中、選取高亮、Inspector 修改方向／意圖／標籤及獨立刪除；桌面與 PostgreSQL 寫入已實測。
- Group Frame：建立時依內容的實際旋轉邊界加上 padding、可保存名稱、parent 指派、解除群組、整組移動、巢狀 descendant 操作、循環 parent 防護，以及鎖定／layer／顏色 Inspector。單一或多選 Node 拖入 Group／泳道時會以整個選取範圍的實際旋轉邊界中心判斷最深層未鎖定目標並高亮，放開後以同一筆 transaction 保存批次移動與 parent；拖出所有 Group 則解除 parent，整筆操作可一次 Undo／Redo。含 Group 的混合選取不會自動 reparent，避免意外改寫巢狀樹。Inspector 與 Command Palette 可依所有巢狀後代的旋轉角點重新收緊或擴張 Group，保留 Group 本身角度並加入 padding。Create／reparent operation 會原子拒絕不存在的 parent、非 Group parent 與同批建立的 parent cycle，避免 AI proposal／匯入資料建立非法階層。Node drag、Group drag 與鍵盤微移共用群組樹移動規則；Group 含任一鎖定 descendant 時整棵不移動，不會破壞相對位置。
- Clipboard：`⌘/Ctrl+C/X/V/D`，複製選取 Node／Group、巢狀內容與內部 relations，貼上時重建 ID 並以單一 transaction 進入 Undo；手機不需外接鍵盤，可從中央 Menu 貼上，並從 bottom sheet 執行複製、剪下與再製。貼上前會驗證 BoarderLess format／schema version、非空且唯一的物件 ID、有限且在安全範圍內的 transform、支援的 Node shape、完整且無循環的 Group parent、Relation 端點與方向；空白、外部文字、未來版本或損壞內容只顯示非阻塞提示，不會改動 Workspace 或讓 UI 因 domain constructor 失敗而中斷。
- Object Library：內建 Thought、Key Idea、Supporting Pair、Comparison Pair，可拖曳到 Canvas 指定位置或插入中央；無效 drop 不建立 history。
- Quick Scheme：v2 payload 保存 Node、Group、巢狀 parent、鎖定、z-order 與內部 relation；方案庫可瀏覽視覺縮圖與摘要、命名、改名、插入與刪除，並相容既有 v1 資料。
- Find & Navigate：`⌘/Ctrl+K` Command Palette，可搜尋命令、思想文字、具名 Group／泳道，以及 Relation 的來源、目標、意圖或標籤；顯示不可用原因並可用方向鍵執行，Node／Group 會置中選取，Relation 則以兩端中點置中並開啟其 Inspector。
- Onboarding：空白 Workspace 顯示 First Thought 與 Object Library 入口，不再只呈現無提示的畫布；手機／分割畫面會依實際可用寬度縮放卡片並自動換行操作，不再顯示僅適用實體鍵盤的 `N` 提示，桌面仍保留完整快捷鍵說明。
- AI Cowork foundation：selection-only／prompt-only context snapshot、串流 provider abstraction、proposal preview、部分接受 transaction、拒絕與版本衝突模型；尚未接 provider transport。
- Backend REST integration：dev identity、Workspace session 保存、projection 載入、序列化 optimistic submit、衝突重載、模糊網路失敗後的權威狀態復原與 Retry。所有 domain 批次操作在送出前會依後端合約保留為支援的複數 payload，或展開為連續 client sequence；批次文字編輯亦會逐 Node 展開並保留各自 expected version，不會在 optimistic 套用後才因單筆 mapping 限制失敗回滾。文字、Node 顏色與 Group 標題等部分屬性更新只送出真正變更的欄位，並已確認後端使用 JSONB 淺層合併，不會因改色清掉文字或因改名清掉樣式；App 端另有 mapping 契約測試防止退化。Projection 邊界會明確拒絕未知 object type／relation direction、重複 ID、無效版本、malformed transform／property、非法 parent 階層、自連 relation 與 dangling relation，不會把不支援或損壞的正式內容靜默丟棄或套用預設值後假裝載入成功。
- Backend Workspace 驗收：對正式 dev server 完成兩個 Workspace 的建立、列出、改名、切換後資料保留、operation activity、editor 可改名但 owner-only 刪除、刪除後清單一致性與測試資料清除；所有契約均通過。
- Workspace 管理：同一個 dev identity 可列出、建立、切換、重新命名與刪除 Workspace；rename 依 owner／editor 權限、delete 僅限 owner 並要求二次確認。切換或管理前會以共用 policy 確認本機提交佇列已清空、同步已結束，且 Node 編輯、Inspector／Scheme 文字草稿、建立草稿、拖曳、變形、連線、框選與 Library drag 均已結束；policy 具逐項單元測試。任何正式內容操作或遠端 catch-up 都會解除既有刪除確認，避免沿用過期的危險意圖。成功切換後會重設 selection、history 與畫布暫態狀態，且會記住最後開啟的 Workspace。刪除目前或最後一個 Workspace 後會安全開啟其他空間或建立預設空間；若已記住的 Workspace 不再存在，啟動時會改開啟仍可存取的 Workspace，而不會直接建立另一個使用者。iPhone 17 Simulator 已透過正式 UI 建立並開啟一次性空 Workspace，冷啟後成功恢復同一 Workspace；精確清理該測試 Workspace 後，再次冷啟會回退到原本的 `My thinking space`，並將偏好中的 Workspace ID 更新為仍存在的 ID。正式 UI 改名也已用暫時名稱完成後端回寫、改回原名稱及冷重啟持久化驗收。另以只暫停 operation POST 的本機代理實測 pending-save 狀態：App 顯示 `Saving 1 change…`，Workspace 改名、刪除與建立按鈕均停用並提示等待儲存；代理與測試 App 隨即終止，暫停的操作未送達後端，正常版本重開後回到權威狀態。先前測試資料已清理；目前後端只額外保留等待使用者確認刪除的空白 `Delete acceptance 2026-09-28` Workspace。
- Collaboration bridge：App 閒置時每 3 秒探測 Workspace metadata 與 REST operation log；內容版本前進時重載 projection，遠端改名或自己的角色變更即使沒有 Canvas operation 也會更新，且同步反映至 Workspace 清單。更新後保留仍存在的選取，並安全清空可能覆蓋他人變更的本機 Undo history。viewer／commenter 仍可平移、選取與查看 Inspector，但建立、拖曳、編輯、刪除及 history mutation 從 UI 邊界停用，不會先 optimistic 修改再被伺服器回滾。Members 面板會列出 display name、user ID、角色與自己的可分享 ID；owner 可用既有成員 API 新增或更新 editor／commenter／viewer，撤銷權限要求二次點擊確認，其他角色只能查看。若目前成員權限遭遠端撤銷或 Workspace 已不存在，App 會立即鎖住畫布、關閉成員管理並明確提示存取已撤銷；若遠端 projection 已包含本版無法安全解讀的資料，App 會保留最後可讀狀態、停止編輯與輪詢並提示更新或 Retry，不會在過期內容上繼續提交。已用獨立 client 提交／還原遠端變更做桌面端到端驗證；真正 presence、cursor 與即時 fan-out 仍等待 WebSocket。
- Mobile 基礎支援：單指平移、雙指縮放，以及具有 44dp 隱形命中區、22dp 低干擾視覺尺寸的 resize／rotate／connector handles；三種控制點不會因提高觸控成功率而遮住更多 Node，Resize／Rotate 另提供 VoiceOver 名稱與拖曳用途。手機／分割畫面不再顯示貼齊上下左右的完整工具列與面板，而是在 iOS safe drawing inset 內保留低干擾的圖標 Menu 入口。Canvas 工具、Workspace、Layers、History、Library、Schemes 與 Command Palette 使用中央可捲動 modal；Node／Group／Relation Inspector 則改為避開 Home Indicator 的底部待命 bottom sheet，初次選取只顯示 64dp 標題與拖曳把手，不會自動展開或把 Node 強制切到文字編輯。使用者可向上拖曳或點擊箭頭展開；開啟中央面板時 Inspector 會保留選取並自動收回 64dp 待命列，兩者同時存在且不互相遮擋。手機文字編輯改由「編輯文字」明確觸發，刪除移至「重用與動作」分類底部。中央選單另提供不依賴鍵盤修飾鍵的多選模式：逐一點擊 Node／Group 即可加入或移出 selection，點擊空白畫布不會清除既有多選，Menu 圖標會顯示啟用狀態；選取兩個以上物件後可由 bottom sheet 的「重用與動作」建立群組，並可直接清除 selection 或再次切換模式關閉。Inspector 內容依「內容與狀態／外觀、變形與排列／重用與動作」分類，預設全部展開，各分類可獨立收合且狀態會保存至裝置偏好供下次重開沿用；自訂顏色與 Color Palette／Color Picker 保留在外觀分類。Compact 判斷同時考慮寬度與短邊高度，因此 iPhone 橫向不會誤切回桌面頂部工具列；底部同步狀態限制為具側邊留白的單行 pill，完整訊息仍保留給輔助技術，中央 Modal／Command Palette 開啟時則隱藏 Menu 入口與狀態，避免在低高度畫面遮住可捲動內容。Inspector 本身不再觸發全畫面 scrim 或清除 selection。Command Palette 的 compact surface 直接套用 safe drawing inset，避免旋轉、鍵盤或較小視窗時貼近系統區域；其他中央 modal 仍以全畫面 scrim 阻止背景 Canvas 誤選與誤拖，點擊外側可關閉。iOS 後端位址可由 Xcode build setting 設定，模擬器預設使用 IPv4 loopback，實機可切換為 Mac LAN 位址且具本機網路用途說明。iPhone 17／iOS 27 Simulator 已完成本次版本的完整 Xcode build、安裝、正式 dev backend 連線、Node 選取不自動編輯、bottom sheet 展開／收合、分類獨立收合、中央選單共存不遮擋，以及 Color Picker 開啟／取消的實際畫面與無障礙樹驗收；等待實機觸控手勢驗收。Xcode build phase 可在未設定 `JAVA_HOME` 時自動尋找 JDK。
- Compact 選單分類：手機畫布選單不再以單一長列堆疊所有按鈕，改分為「建立與導覽／歷程動作／畫布檢視」三區；各區預設展開、可獨立收合，收合狀態立即保存並在重開 App 後恢復。選單與 Inspector 使用不同的 namespaced 偏好，兩者不會互相改變收合狀態；分類標題提供按鈕角色及 VoiceOver 展開／收合狀態。桌面工具列會等到 Canvas 取得有效尺寸且確認為寬畫面後才渲染，避免 iPhone 冷啟時在動態島後方閃過一幀桌面工具列。
- Mobile 多選快捷操作：多選模式在 Workspace 有內容時，中央 Menu 直接顯示橫向、低高度的快捷列；可一鍵全選、清除 selection，兩個以上物件亦可直接「組成群組」，不必先展開 bottom sheet 再尋找分類。「全選」與桌面 `⌘/Ctrl+A` 都只選擇 hierarchy roots，Group 代表其所有 descendants，不會同時選到 parent 與 child 而破壞後續群組、移動或剪貼簿操作。逐項加入選取時若點到既有選取的祖先或後代，最後點擊的物件會取代同一路徑上的衝突項目，同時保留其他兄弟物件。建立 Group 仍以 Create＋Reparent 的單一 transaction 進入 Undo，只有 domain history 確認 optimistic 套用成功後才選取新 Group 並關閉多選模式；不相容 parent、鎖定或不同 parent 時保留 selection 並顯示原因。Viewer 可使用多選與全選查看內容，但 mutation 快捷操作會依權限停用。
- Motion feedback：Node 選取縮放／陰影及 Group 選取回饋具動畫，Reduce Motion 啟用時立即降級。
- Desktop 實際連線 PostgreSQL 驗證；Android、iOS simulator、JS、Wasm 編譯驗證。
