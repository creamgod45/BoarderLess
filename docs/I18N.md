# 多語系（i18n）

介面文字放在 `shared/src/commonMain/composeResources/files/i18n/`，一個語言一個 JSON：

| 檔案 | 用途 |
| --- | --- |
| `en.json` | 英文原文，也是 key 的唯一來源 |
| `zh-TW.json` | 繁體中文翻譯 |
| `languages.json` | 可選語言清單（tag、原生名稱、系統語系對應） |

## Key 與程式碼

JSON 以命名空間巢狀組織，建置時 `:shared:generateI18nStrings` 會從 `en.json` 產生 `Strings` 物件，
所以程式碼用的是編譯期檢查過的 key，而且內建英文預設值：

```json
{ "status": { "opening": "Opening {title}…", "savingChanges": { "one": "Saving {count} change…", "other": "Saving {count} changes…" } } }
```

```kotlin
Strings.common.close()                 // 無參數：LocalizedText，呼叫取得目前語言的文字
Strings.status.opening(summary.title)  // {title} 變成函式參數
Strings.status.savingChanges(count)    // one/other 物件 → 複數，第一個參數是 count
```

- 佔位符用具名的 `{name}`；翻譯可以調整順序，但名稱必須和 `en.json` 相同。
- 複數用 `{"one": …, "other": …}`；中文等不分單複數的語言只寫 `other` 即可。
- 某語言缺少某個 key 時會自動退回英文。

## 新增或修改文字

1. 在 `en.json` 適當的命名空間加入 key（改了英文原文就一併更新其他語言）。
2. 在每個語言檔加上同一個 key 的翻譯。
3. 程式碼改用 `Strings.<命名空間>.<key>`；不要在 UI 寫死字串，也不要呼叫 `tr("…")`。

## 新增語言

1. 複製 `en.json` 為 `<tag>.json`（例如 `ja.json`）並翻譯內容。
2. 在 `languages.json` 加入 `{"tag": "ja", "name": "日本語"}`；若要讓其他系統語系也對應到它，
   加上 `"matches": ["…"]`。
3. 不需要修改程式碼：命令面板的語言選項與「跟隨系統」會自動包含新語言。

`LocalizationCatalogTest`（jvmTest）會檢查每個語言檔的 key、類型與佔位符都和 `en.json` 一致、
`languages.json` 列出所有語言檔，以及原始碼中沒有殘留的 `tr("…")` 寫死字串。
