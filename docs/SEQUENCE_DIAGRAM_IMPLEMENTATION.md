## 已實作且有執行證據

`domain/sequence/SequenceDiagramDraft.kt` 定義版本化 `boarderless.sequence-draft.v1`。participants list 是顯式欄位順序，含 Participant／Actor role；message 有独立 step ID、source／target ID、text、kind 與 dashed，self-message 由明確相同端點表示。block 是 Alt／Loop／Parallel union，branches 含 label 與 ordered child steps；巢狀樹保留 containment，不從 x/y、UUID、zIndex 或普通圖 cycle 猜次序。Parallel branches 的 list 是穩定呈現順序，不當作跨分支的執行先後。

限制：1..32 participants、1..512 messages、最多128 blocks／16層 nesting、alt/par 2..16 branches、loop 1 branch；每branch非空、step identities全域唯一、端點必存在、label每筆最多4KiB／整體256KiB，明確拒絕非法 Unicode 與 plain-text dialect 以外的 markup／entity／statement escapes。`validatedSnapshot` 在 bounded validation 後深拷貝 caller-owned lists；export／layout／editing 均先核實與capture，不讓事後清空／污染原 list 變成已驗資料。這不是完整原生文件 decoder／跨裝置 transfer codec。

`MermaidSequenceAdapter.kt` 的 dialect 是 `boarderless.mermaid-sequence.v1`，共同 Kotlin core，沒有 JS execution。支持 sequenceDiagram header、participant/actor 與 plain alias、implicit participant 首次出現順序、六種單向 arrow（->>／-->>／-)／--)／->／-->）、alt/else、loop、par/and、巢狀 end 及整行普通 %% comments。聲明只接受在第一個 body statement 前，避免重排參與者。64KiB source／2048 lines；unsupported statement、未閉合／錯 branch／empty branch／錯 arrow 等輸出常數診斷碼與行號，沒有 partial usable draft。Config directives／links／activation／notes／creation/destruction／bidirectional arrows 等目前明確不支持，不能當作任意 Mermaid 圖型轉換。

此 dialect 將 solid filled arrow 記為 Call、dotted filled arrow 記為 Return，async open arrow 記為 Async、無箭頭線記為 Signal，保留其 dashed flag。這是可編輯圖示分類，不證明業務呼叫配對、runtime response 或並行因果。Mermaid 本身沒有 message ID 語法；結構化 draft 保留 IDs，純 Mermaid export 不能宣稱外部重新匯入保留任意原 IDs。純 exporter 只產生已支持 tree 的語法，不拼接使用者程式片段。

`SequenceDraftEditing.kt` 依 block ID＋branch index 編輯／插入／移動 step，參與者重排必須是 exact permutation；保持未改 step／block IDs 和其他分支，修改後再次完整驗證。`SequenceDiagramLayout.kt` 是 semantic row plan：participant headers／lifelines、message lines／self-message 非零四點外側 route、nested block bounds／branch bands。訊息列由明確樹順序產生；parallel 的視覺 bands 不表示時間串行。尚未接正式 canvas renderer、文字測量、pointer／accessibility 或 clipping。
